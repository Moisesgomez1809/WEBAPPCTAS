# **App Name**: Acta Fusion

## Core Features:

- PDF Upload: Allow the user to drag and drop the birth certificate PDF.
- PDF Preview: Provide a preview of the uploaded PDF.
- Entity Recognition: Use a tool powered by AI to identify the issuing entity from the birth certificate PDF.
- Reverse Side Selection: Use a tool powered by AI to match the recognized entity with the corresponding reverse side PDF stored in the Google Drive folder (https://drive.google.com/drive/folders/1XUWhogphvvamI3r8EAitrrRbpL2HN9uo?usp=sharing).
- PDF Fusion: Combine the original birth certificate and the selected reverse side into a single PDF.
- Combined PDF Preview: Provide a preview of the combined PDF.
- PDF Download: Enable users to download the combined PDF.

## Style Guidelines:

- Primary color: Sky blue (#87CEEB) to represent trust and clarity.
- Background color: Light gray (#F0F8FF) to ensure readability.
- Accent color: Soft green (#98FB98) to highlight interactive elements.
- Body and headline font: 'Inter', a sans-serif font, for a modern, neutral look, suitable for both headlines and body text.
- Use clear, recognizable icons for actions like upload, download, and preview.
- Keep the layout clean and intuitive, with a clear separation of sections for upload, preview, and download.
- Use subtle transitions and animations to provide feedback on actions like uploading and processing the PDF.
